# تیزبازی 🧠

پلتفرم وب بازی‌های تمرین مغزی به زبان فارسی (راست‌چین): ۱۰ بازی، احراز هویت اختیاری (مهمان یا ثبت‌نام‌شده)، XP و سطح،
streak روزانه، چالش روزانه، نشان‌ها، لیدربورد در پنج بازهٔ زمانی (با هفتهٔ شنبه‌شروع و ماه/سال شمسی)، و دکمهٔ بازی ترکیبی تصادفی.

## فناوری‌ها

| بخش | انتخاب |
| --- | --- |
| فریم‌ورک | Nuxt 4 (Vue 3 + Nitro) با TypeScript؛ فرانت و بک‌اند یکپارچه |
| پایگاه داده | PostgreSQL + Prisma 7 |
| احراز هویت | JWT در کوکی `HttpOnly` / `SameSite=Strict` (+ `Secure` در production)، bcrypt، اثرانگشت دستگاه (SHA-256) |
| اعتبارسنجی | zod (پیام‌ها فارسی) |
| استایل | Tailwind CSS + CSS Custom Properties (تم روشن/تیره) · فونت Vazirmatn |
| تست | Vitest (واحد + یکپارچگی)، Playwright (E2E) |

## راه‌اندازی

پیش‌نیازها: Node.js ‏22 یا بالاتر و یک PostgreSQL در حال اجرا (Docker لازم نیست).

```bash
npm install
```

۱. دیتابیس بسازید (نام دلخواه، مثلاً `tizbazi`):

```bash
psql -U postgres -c "CREATE DATABASE tizbazi ENCODING 'UTF8'"
```

۲. فایل محیطی را از نمونه بسازید و مقدارها را پر کنید:

```bash
cp .env.example .env
```

| متغیر | توضیح |
| --- | --- |
| `DATABASE_URL` | مثلاً `postgresql://postgres:PASSWORD@localhost:5432/tizbazi` |
| `JWT_SECRET` | رشتهٔ تصادفی حداقل ۳۲ کاراکتری (مثلاً با `openssl rand -hex 32`) |

۳. جدول‌ها را بسازید و بانک‌های داده را وارد کنید:

```bash
npm run db:deploy   # اعمال مایگریشن‌ها
npm run seed        # کلمات، دسته‌ها، جفت‌های متضاد/مترادف، ضرب‌المثل‌ها و گروه‌های کلمه
```

۴. اجرا:

```bash
npm run dev         # http://localhost:3000
```

برای production: `npm run build` و سپس `node .output/server/index.mjs` (متغیرهای `DATABASE_URL` و `JWT_SECRET` را تنظیم کنید).

## اسکریپت‌ها

| دستور | کار |
| --- | --- |
| `npm run dev` | سرور توسعه |
| `npm run build` | ساخت production |
| `npm run db:migrate` | ساخت مایگریشن جدید در توسعه (تعاملی) |
| `npm run db:deploy` | اعمال مایگریشن‌های موجود |
| `npm run db:generate` | ساخت کلاینت Prisma (بعد از هر تغییر `schema.prisma`) |
| `npm run seed` | ورود بانک‌های داده |
| `npm test` | تست‌های واحد (منطق بازی‌ها، امتیاز، بازه‌ها، گیمیفیکیشن) |
| `npm run test:integration` | تست‌های API روی سرور در حال اجرا (`TIZ_BASE_URL` پیش‌فرض `http://localhost:3100`) |
| `npm run test:e2e` | تست سرتاسری Playwright (با Edge نصب‌شده؛ `E2E_CHANNEL=chrome` برای Chrome) |
| `npm run lint` / `npm run format` | ESLint / Prettier |

> تست‌های یکپارچگی و E2E کاربران آزمایشی با پیشوند «تست» یا «ای‌تو‌ای» در دیتابیس می‌سازند؛ آن‌ها را روی دیتابیس واقعی اجرا نکنید.

## بازی‌ها

استروپ · حرف گمشده · محاسبات ذهنی · محاسبات سریع · حافظه ترتیبی · دسته‌بندی سریع · متضاد/مترادف · ضرب‌المثل ناقص · کلمهٔ مزاحم · حافظهٔ عددی معکوس

منطق تولید سؤال هر بازی در `shared/games/` (توابع خالص و قابل تست) است و رابط هر بازی در `app/pages/games/`.

## ساختار

```
app/            صفحات، کامپوننت‌ها، composableها و متن‌های فارسی (app/i18n/fa.ts)
server/api/     auth · scores · leaderboard · gamification · games (mix و دورهای بازی)
server/utils/   Prisma، احراز هویت، امتیازدهی، لیدربورد، streak
shared/         منطق مشترک کلاینت/سرور: بازی‌ها، گیمیفیکیشن، بازه‌های زمانی، چالش روزانه، zod
prisma/         schema، مایگریشن‌ها، seed و prisma/data (بانک‌های داده)
tests/          unit · integration · e2e
scripts/        build-words.mjs (ساخت بانک کلمات «حرف گمشده»)
```

## نکات طراحی

- **هفته و تقویم:** هفته از شنبه شروع می‌شود و «این ماه / امسال» بر پایهٔ ماه و سال **شمسی** و به وقت تهران محاسبه می‌شود (نه `date_trunc` میلادی PostgreSQL). منطق در `shared/periods.ts` است.
- **مهمان و ارتقا:** کاربر مهمان با اثرانگشت دستگاه شناخته می‌شود. ثبت‌نام همان دستگاه، همان کاربر را ارتقا می‌دهد و امتیازها حفظ می‌شود. اثرانگشت به‌تنهایی اجازهٔ ورود به حساب ثبت‌شده نمی‌دهد.
- **امتیاز بازی ترکیبی** از امتیازهای واقعاً ذخیره‌شده سرور محاسبه می‌شود، نه از عددی که کلاینت می‌فرستد.
- **محدودیت نرخ:** حداکثر یک ذخیرهٔ امتیاز در ۳ ثانیه برای هر کاربر (در حافظهٔ پردازش؛ برای چند نمونهٔ سرور باید به Redis منتقل شود).
- **نشان «صدرنشین»** وقتی داده می‌شود که کاربر در لیدربورد هفتگی (مجموع امتیاز) اول باشد و حداقل دو بازیکن در هفته امتیاز داشته باشند.

## بانک‌های داده

- **حرف گمشده:** تقاطع واژه‌نامهٔ [`an-array-of-persian-words`](https://www.npmjs.com/package/an-array-of-persian-words) (MIT) با فهرست بسامدی [FrequencyWords](https://github.com/hermitdave/FrequencyWords)، ساخته‌شده با `scripts/build-words.mjs` (۴۰۰۰ کلمه). چند اسم خاص یا کلمهٔ عامیانه ممکن است باقی مانده باشد.
- **دسته‌بندی، متضاد/مترادف، ضرب‌المثل، کلمهٔ مزاحم:** فایل‌های `prisma/data/*.json` به‌صورت دستی تهیه شده‌اند و نیاز به بازبینی انسانی دارند. برای ویرایش، فایل را عوض کنید و `npm run seed` را دوباره بزنید (ردیف‌های تکراری نادیده گرفته می‌شوند).

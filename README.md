# تیزبازی 🧠

پلتفرم وب بازی‌های تمرین مغزی به زبان فارسی (راست‌چین): ۱۰ بازی، احراز هویت اختیاری (مهمان یا ثبت‌نام‌شده)، XP و سطح،
streak روزانه، چالش روزانه، نشان‌ها، لیدربورد در پنج بازهٔ زمانی (با هفتهٔ شنبه‌شروع و ماه/سال شمسی)، و دکمهٔ بازی ترکیبی تصادفی.

## فناوری‌ها

| بخش | انتخاب |
| --- | --- |
| فریم‌ورک | Nuxt 4 (Vue 3 + Nitro) با TypeScript؛ فرانت و بک‌اند یکپارچه |
| پایگاه داده | PostgreSQL + Prisma 7 |
| احراز هویت | JWT در کوکی `HttpOnly` / `SameSite=Strict` (+ `Secure` در production)، bcrypt، اثرانگشت دستگاه (SHA-256) |
| اعتبارسنجی | zod (پیام‌ها فارسی) |
| استایل | Tailwind CSS + CSS Custom Properties (تم روشن/تیره) · فونت Vazirmatn |
| تست | Vitest (واحد + یکپارچگی)، Playwright (E2E) |

## راه‌اندازی

پیش‌نیازها: Node.js ‏22 یا بالاتر و یک PostgreSQL در حال اجرا (Docker لازم نیست).

```bash
npm install
```

۱. دیتابیس بسازید (نام دلخواه، مثلاً `tizbazi`):

```bash
psql -U postgres -c "CREATE DATABASE tizbazi ENCODING 'UTF8'"
```

۲. فایل محیطی را از نمونه بسازید و مقدارها را پر کنید:

```bash
cp .env.example .env
```

| متغیر | توضیح |
| --- | --- |
| `DATABASE_URL` | مثلاً `postgresql://postgres:PASSWORD@localhost:5432/tizbazi` |
| `JWT_SECRET` | رشتهٔ تصادفی حداقل ۳۲ کاراکتری (مثلاً با `openssl rand -hex 32`) |

۳. جدول‌ها را بسازید و بانک‌های داده را وارد کنید:

```bash
npm run db:deploy   # اعمال مایگریشن‌ها
npm run seed        # کلمات، دسته‌ها، جفت‌های متضاد/مترادف، ضرب‌المثل‌ها و گروه‌های کلمه
```

۴. اجرا:

```bash
npm run dev         # http://localhost:3000
```

برای production: `npm run build` و سپس `node .output/server/index.mjs` (متغیرهای `DATABASE_URL` و `JWT_SECRET` را تنظیم کنید).

## اسکریپت‌ها

| دستور | کار |
| --- | --- |
| `npm run dev` | سرور توسعه |
| `npm run build` | ساخت production |
| `npm run db:migrate` | ساخت مایگریشن جدید در توسعه (تعاملی) |
| `npm run db:deploy` | اعمال مایگریشن‌های موجود |
| `npm run db:generate` | ساخت کلاینت Prisma (بعد از هر تغییر `schema.prisma`) |
| `npm run seed` | ورود بانک‌های داده (سرورِ در حال اجرا ظرف ۱۰ ثانیه دادهٔ تازه را برمی‌دارد) |
| `npm run build:esm-famil` | ساخت دوبارهٔ بانک اسم‌فامیل از بسته‌های داده و فهرست‌های دستی |
| `npm test` | تست‌های واحد (منطق بازی‌ها، امتیاز، بازه‌ها، گیمیفیکیشن) |
| `npm run test:integration` | تست‌های API روی سرور در حال اجرا (`TIZ_BASE_URL` پیش‌فرض `http://localhost:3100`) |
| `npm run test:e2e` | تست سرتاسری Playwright (با Edge نصب‌شده؛ `E2E_CHANNEL=chrome` برای Chrome) |
| `npm run lint` / `npm run format` | ESLint / Prettier |

> تست‌های یکپارچگی و E2E کاربران آزمایشی با پیشوند «تست» یا «ای‌تو‌ای» در دیتابیس می‌سازند؛ آن‌ها را روی دیتابیس واقعی اجرا نکنید.

## بازی‌ها (۲۲)

**ورزش ذهن:** استروپ · حرف گمشده · محاسبات ذهنی · محاسبات سریع · حافظه ترتیبی · دسته‌بندی سریع · متضاد/مترادف · ضرب‌المثل ناقص · کلمهٔ مزاحم · حافظهٔ عددی معکوس

**ادب و بازی‌های ایرانی:**

| بازی | توضیح |
| --- | --- |
| کلمه‌روز | وردل فارسی: کلمهٔ ۵ حرفی در ۶ حدس؛ معمای روزانهٔ مشترک + حالت تمرین؛ جواب فقط در سرور است و امتیاز را سرور ثبت می‌کند |
| اسم‌فامیل | سه دور با سه حرف؛ داوری با بانک دسته‌ها (۱۰ امتیاز) و در غیر این صورت با واژه‌نامه (۳ امتیاز). «فامیل» قاعدهٔ ریشه + پسوند هم دارد (احمدی، تهرانی، حسین‌زاده، دانشور) |
| مشاعره | زنجیرهٔ بیت‌ها با حرف آخر بیت قبل؛ مصراع اولِ بیت بعدی نشان داده می‌شود و بازیکن مصراع دوم را پیدا می‌کند (در سخت، گزینه‌ها هم‌قافیه‌اند) |
| چیستان | چهار گزینه، با راهنمایی که دو گزینهٔ غلط را حذف می‌کند (نصف امتیاز) |
| دوز | دوزِ نه‌تایی در برابر هوش مصنوعی minimax (عمق ۱/۲/۴) |
| معمای شطرنج | مات در ۱ و ۲ حرکت؛ معماها با `scripts/gen-chess.ts` تولید و با chess.js تأیید شده‌اند |

**سفر ذهنی در ایران:** بازار (تومان/ریال، باقی پول، تخفیف) · تقویم ذهنی (روز هفته و تاریخ شمسی) · نقشهٔ ایران (۳۱ استان و مراکز) · کاشی‌کاری (جفت‌یابی نقش‌های SVG) · زنجیرهٔ کلمات (در برابر رایانه) · رمزشکن

منطق تولید سؤال هر بازی در `shared/games/` (توابع خالص و قابل تست) است و رابط هر بازی در `app/pages/games/`.
تصویر هر بازی یک SVG درون‌خطی در `app/components/GameArt.vue` است. صفحهٔ نتیجه بسته به امتیاز واکنش نشان می‌دهد
(رکورد شخصی، عالی، خوب، کم، صفر — `shared/reaction.ts`)؛ برای رکورد و امتیاز عالی کاغذرنگی می‌ریزد.
«کلمه‌روز» و «دوز» در بازی تصادفی نمی‌آیند (`MIX_EXCLUDED`).

## ساختار

```
app/            صفحات، کامپوننت‌ها، composableها و متن‌های فارسی (app/i18n/fa.ts)
server/api/     auth · scores · leaderboard · gamification · games (mix و دورهای بازی)
server/utils/   Prisma، احراز هویت، امتیازدهی، لیدربورد، streak
shared/         منطق مشترک کلاینت/سرور: بازی‌ها، گیمیفیکیشن، بازه‌های زمانی، چالش روزانه، zod
prisma/         schema، مایگریشن‌ها، seed و prisma/data (بانک‌های داده)
tests/          unit · integration · e2e
scripts/        build-words.mjs (ساخت بانک کلمات «حرف گمشده»)
```

## نکات طراحی

- **هفته و تقویم:** هفته از شنبه شروع می‌شود و «این ماه / امسال» بر پایهٔ ماه و سال **شمسی** و به وقت تهران محاسبه می‌شود (نه `date_trunc` میلادی PostgreSQL). منطق در `shared/periods.ts` است.
- **مهمان و ارتقا:** کاربر مهمان با اثرانگشت دستگاه شناخته می‌شود. ثبت‌نام همان دستگاه، همان کاربر را ارتقا می‌دهد و امتیازها حفظ می‌شود. اثرانگشت به‌تنهایی اجازهٔ ورود به حساب ثبت‌شده نمی‌دهد.
- **امتیاز بازی ترکیبی** از امتیازهای واقعاً ذخیره‌شده سرور محاسبه می‌شود، نه از عددی که کلاینت می‌فرستد.
- **محدودیت نرخ:** حداکثر یک ذخیرهٔ امتیاز در ۳ ثانیه برای هر کاربر (در حافظهٔ پردازش؛ برای چند نمونهٔ سرور باید به Redis منتقل شود).
- **نشان «صدرنشین»** وقتی داده می‌شود که کاربر در لیدربورد هفتگی (مجموع امتیاز) اول باشد و حداقل دو بازیکن در هفته امتیاز داشته باشند.

## بانک‌های داده

- **حرف گمشده:** تقاطع واژه‌نامهٔ [`an-array-of-persian-words`](https://www.npmjs.com/package/an-array-of-persian-words) (MIT) با فهرست بسامدی [FrequencyWords](https://github.com/hermitdave/FrequencyWords)، ساخته‌شده با `scripts/build-words.mjs` (۴۰۰۰ کلمه). چند اسم خاص یا کلمهٔ عامیانه ممکن است باقی مانده باشد.
- **دسته‌بندی، متضاد/مترادف، ضرب‌المثل، کلمهٔ مزاحم:** فایل‌های `prisma/data/*.json` به‌صورت دستی تهیه شده‌اند و نیاز به بازبینی انسانی دارند. برای ویرایش، فایل را عوض کنید و `npm run seed` را دوباره بزنید (ردیف‌های تکراری نادیده گرفته می‌شوند).
- **واژه‌نامهٔ تأیید** (`dictionary.json`، حدود ۱۳۹ هزار کلمه) از همان بستهٔ MIT با `scripts/build-dictionary.mjs` ساخته شده و برای اسم‌فامیل، زنجیرهٔ کلمات و حدس‌های مجاز کلمه‌روز به کار می‌رود.
- **اسم‌فامیل** (`npm run build:esm-famil`): اسم‌ها از [`persian-names`](https://www.npmjs.com/package/persian-names) (MIT؛ داده از PNGT-26K با Apache-2.0)، شهرهای ایران از [`iran-cities-json`](https://www.npmjs.com/package/iran-cities-json) (MIT)، نام فارسی کشورها از [`i18n-iso-countries`](https://www.npmjs.com/package/i18n-iso-countries) (MIT)، به‌اضافهٔ فهرست‌های دستی `esm-famil-hand.json` و `esm-famil-extra.json` (حیوان، غذا، میوه، رنگ، اشیا، فامیل، شهرهای جهان). کد بسته‌ها اجرا نمی‌شود؛ فقط داده‌شان خوانده می‌شود.
- **زنجیرهٔ کلمات:** کلمه‌های رایانه فقط اسم‌های عام شناخته‌شده‌اند (همان فهرست‌های دستی + دسته‌ها؛ محتوای `chain-words`)، نه بانک بسامدی زیرنویس‌ها.
- **نقشهٔ ایران:** مرز استان‌ها از بستهٔ [`react-iran-map`](https://www.npmjs.com/package/react-iran-map) (MIT، © Sima Mojtahedi) با `scripts/build-iran-map.mjs` استخراج شده است؛ مختصات مراکز استان‌ها (برای انتخاب استان‌های همسایه) تقریبی است.
- **بازی‌های ایرانی** (جدول `ContentItem`): جواب‌های کلمه‌روز، بیت‌های مشاعره (اشعار کلاسیک، مالکیت عمومی) و چیستان‌ها دستی تهیه و یک بار بازبینی شده‌اند.
- **معماهای شطرنج** (`chess-puzzles.json`، ۸۰/۸۰/۶۰): از [پایگاه معماهای Lichess](https://database.lichess.org/#puzzles) (CC0)، یعنی موقعیت‌های بازی‌های واقعی. فقط چند مگابایت اول فایل لازم است:
  ```bash
  curl -r 0-6000000 -o head.csv.zst https://database.lichess.org/lichess_db_puzzle.csv.zst
  npx tsx scripts/build-chess-lichess.ts head.csv.zst
  ```
  موقعیت‌های «نوبت سیاه» قرینه می‌شوند تا همیشه سفید حرکت کند، و هر معما با حل‌کنندهٔ خود بازی دوباره تأیید می‌شود
  (مات در ۱: دقیقاً یک حرکت مات · مات در ۲: حرکت اول راه‌حل در برابر هر دفاعی مات می‌دهد). شناسهٔ هر معما در `source` آمده است.
  (`scripts/gen-chess.ts` مولد قدیمی موقعیت‌های تصادفی است.)

## اپ اندروید (کافه‌بازار)

وب‌اپ یک PWA کامل است (manifest، سرویس‌ورکر، صفحهٔ آفلاین، آیکون‌ها با `npm run build:icons`) و با TWA به اپ اندروید تبدیل می‌شود. مراحل Android Studio و تأیید دامنه (`/.well-known/assetlinks.json`، متغیرهای `TWA_PACKAGE` و `TWA_SHA256`) در [docs/android-twa.md](docs/android-twa.md) است.
